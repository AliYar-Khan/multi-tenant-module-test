# Research: Mini Multi-Tenant SaaS Module

## Overview
This document summarizes research findings and references for building a secure, scalable, and maintainable multi-tenant SaaS module using Vite (React), Node.js (Express), Zod validation, and MongoDB.

## Key Topics
- Multi-tenant architecture patterns (subdomain routing, tenant isolation)
- Secure authentication (JWT, password hashing)
- Role-based access control
- Real-time dashboard updates (WebSockets, polling)
- Integration with external APIs (Ultravox)
- ENV configuration and secrets management
- Testing strategies for SaaS modules
